# Roshambo (Rock, Paper, Scissors)

A clean and interactive Rock, Paper, Scissors game that lives directly in your browser. Play classic head-to-head matches against a randomized computer opponent, test your luck, and keep track of your win streaks with real-time score counters.

## Features

* Fast, one-click interactive controls
* Dynamic round outcome tracking (Win, Lose, Tie)
* Real-time score counter for both player and computer
* One-click reset to start a fresh match session
* Fully responsive layout for desktop and mobile

## Highlights

* Made using semantic HTML5, modern CSS3, and vanilla JavaScript
* Zero external frameworks or heavy dependencies
* Lightweight and instant load times
* Simple, beginner-friendly DOM manipulation logic
